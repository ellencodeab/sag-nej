# Arbetslogg – Säg nej!

## Projektbeskrivning
Jag utvecklar webbapplikationen "Säg nej!" som hämtar ursäkter från No as a Service API. Användaren kan klicka på en knapp för att få en ursäkt och se tidigare ursäkter i en historik.

## Genomfört arbete
- Skapat projektet med Vite.
- Byggt sidans struktur med HTML och JavaScript.
- Använt JavaScript-moduler och kopplat applikationen till ett externt API.
- Skapat en historik för tidigare ursäkter.
- Använt Sass för sidans design och responsiva layout.
- Publicerat webbplatsen med GitHub Pages.
- Skrivit README och lagt till en skärmbild.

## Utmaningar
En utmaning var att konfigurera publiceringen med GitHub Actions och GitHub Pages. Jag behövde testa webbplatsen och kontrollera att den fungerade efter publiceringen.

## Individuellt arbete
